# CodeNest

CodeNest is an AI-style coding learning platform for Python, SQL/MySQL, Java, JavaScript, HTML/CSS, and AI/ML basics.

## Current version

- Next.js + TypeScript
- Responsive dark learning dashboard
- Course cards
- Chat-style AI tutor interface
- Beginner-friendly learning flow
- Ready for AI API integration

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## AI integration

The current UI uses a local placeholder response. The next phase can connect a supported AI provider through a server-side API route and an environment variable. Never commit an API secret to GitHub.
